- **NFR-01 — Persistence:** Important world state, customers, items, and histories must survive saving and loading.
    
- **NFR-02 — Modularity:** Systems should be sufficiently independent to be reused in a larger RPG.
    
- **NFR-03 — Determinism:** Given the same initial state, inputs, and random seed, event resolution should be reproducible for debugging.
    
- **NFR-04 — Performance:** World progression should process discrete events and activities rather than require expensive continuous simulation.
    
- **NFR-05 — Maintainability:** Game rules and event definitions should be easy to modify without rewriting the underlying simulation.
    
- **NFR-06 — Presentation:** The prototype should communicate important state changes clearly through a menu-driven interface.
    
- **NFR-07 — Scope:** The implementation must remain achievable within the 10-week development period.
